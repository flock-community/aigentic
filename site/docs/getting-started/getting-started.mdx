Aigentic is a Kotlin Multiplatform library for building AI agents with a typed DSL. You'll have a working agent in three steps, and a fourth shows you how often it gets the answer right. The rest of this page covers the other modules, Maven, and adding tools.

## Your first agent, step by step

### 1. Add the dependencies

```kotlin title="build.gradle.kts"
plugins {
    kotlin("jvm") version "2.3.0"
    kotlin("plugin.serialization") version "2.3.0"
    application
}

dependencies {
    implementation("community.flock.aigentic:core:{{AIGENTIC_VERSION}}")
    implementation("community.flock.aigentic:gemini:{{AIGENTIC_VERSION}}")
    implementation("io.ktor:ktor-client-cio:{{KTOR_VERSION}}")
}

application {
    mainClass.set("MainKt")
}
```

The `plugin.serialization` line is required: Aigentic uses it to turn your `@AigenticParameter` classes into schemas the model fills in. Using Maven or another provider? See [Installation](#installation) below.

### 2. Write the agent

```kotlin title="src/main/kotlin/Main.kt"
import community.flock.aigentic.core.agent.start
import community.flock.aigentic.core.agent.tool.Outcome
import community.flock.aigentic.core.annotations.AigenticParameter
import community.flock.aigentic.core.dsl.agent
import community.flock.aigentic.gemini.dsl.geminiModel
import community.flock.aigentic.gemini.model.GeminiModelIdentifier

@AigenticParameter
data class Answer(val answer: String)

val kotlinExpert = agent<String, Answer> {
    geminiModel {
        apiKey(System.getenv("GEMINI_API_KEY"))
        modelIdentifier(GeminiModelIdentifier.Gemini3_5Flash)
    }
    task("Answer questions about Kotlin") {
        addInstruction("Keep answers to two sentences")
    }
}

suspend fun main() {
    val run = kotlinExpert.start("How are coroutines different from threads?")
    when (val outcome = run.outcome) {
        is Outcome.Finished -> println(outcome.response?.answer)
        is Outcome.Stuck -> println("Stuck: ${outcome.reason}")
        is Outcome.Fatal -> println("Error: ${outcome.message}")
    }
}
```

`agent<String, Answer>` means the agent takes a `String` and gives you back an `Answer`. The model fills in the data class for you, so there's no JSON to parse.

### 3. Run it

Get a free API key from [Google AI Studio](https://aistudio.google.com/apikey), then run:

```bash
export GEMINI_API_KEY=your-api-key
./gradlew run
```

```text title="Output"
🚀 Agent started!
Coroutines suspend instead of blocking, so thousands of them can share a handful of threads. Threads are managed by the operating system and cost far more to create and switch between.
```

The answer comes from the model, so yours will be worded differently. Next, [see how the pieces fit together](/docs/concepts), [give the agent a tool](#add-a-tool) or [switch to another provider](/docs/dsl/providers).

### 4. Measure how often it's right

One good answer doesn't tell you much. To know how often an agent is right, you need answers you can check, field by field. The [Aigentic Platform](/docs/platform) does that checking for you. This step needs access to the platform, see [Hosting and access](/docs/platform#hosting-and-access).

Add `implementation("community.flock.aigentic:platform:{{AIGENTIC_VERSION}}")` to your dependencies, create an agent called `ticket-classifier` on the platform and keep its secret. Then run a small agent that sorts support tickets, together with the answers you expect:

```kotlin title="src/main/kotlin/Main.kt"
import community.flock.aigentic.core.agent.Expected
import community.flock.aigentic.core.agent.start
import community.flock.aigentic.core.annotations.AigenticParameter
import community.flock.aigentic.core.dsl.agent
import community.flock.aigentic.gemini.dsl.geminiModel
import community.flock.aigentic.gemini.model.GeminiModelIdentifier
import community.flock.aigentic.platform.dsl.platform

@AigenticParameter
data class Ticket(val category: String, val urgent: Boolean)

val ticketClassifier = agent<String, Ticket> {
    geminiModel {
        apiKey(System.getenv("GEMINI_API_KEY"))
        modelIdentifier(GeminiModelIdentifier.Gemini3_5Flash)
    }
    task("Classify the support ticket") {
        addInstruction("Use one of these categories: billing, delivery, product, other")
        addInstruction("A ticket is urgent when the customer lost money or can't use the product")
    }
    platform {
        name("ticket-classifier")
        secret(System.getenv("AIGENTIC_PLATFORM_SECRET"))
    }
}

val tickets = listOf(
    "I was charged twice for my order" to Ticket("billing", urgent = true),
    "My package is a week late, any news?" to Ticket("delivery", urgent = false),
    "The app crashes every time I log in" to Ticket("product", urgent = true),
)

suspend fun main() {
    tickets.forEach { (text, expected) ->
        ticketClassifier.start(text, expected = Expected("first-tickets", expected))
    }
}
```

Open the agent on the platform. Under **Evaluations** you'll find `first-tickets`, with the accuracy of `category` and `urgent` over these three tickets. Three tickets is a start, not a measurement: [From prototype to production](/docs/lifecycle) shows how to grow it into a golden set and use it every time you change the agent.

## Installation

Aigentic can be added to your project using either Gradle or Maven build tools.

<Tabs>
<TabItem value="gradle" label="Gradle">

### Kotlin (JVM)

Add the following to your `build.gradle.kts` file:

```kotlin
plugins {
    kotlin("jvm") version "2.3.0"

    // Kotlinx serialization enables @AigenticParameter to convert Kotlin classes
    // to LLM-compatible formats in order to provide a type safe DSL
    kotlin("plugin.serialization") version "2.3.0"
}

dependencies {
    // Core module
    implementation("community.flock.aigentic:core:{{AIGENTIC_VERSION}}")

    // Provider modules (choose the ones you need)
    implementation("community.flock.aigentic:openai:{{AIGENTIC_VERSION}}")
    implementation("community.flock.aigentic:gemini:{{AIGENTIC_VERSION}}")
    implementation("community.flock.aigentic:ollama:{{AIGENTIC_VERSION}}")
    implementation("community.flock.aigentic:vertexai:{{AIGENTIC_VERSION}}")

    // Tools modules (optional)
    implementation("community.flock.aigentic:http:{{AIGENTIC_VERSION}}")
    implementation("community.flock.aigentic:openapi:{{AIGENTIC_VERSION}}")

    // Platform module (optional): send runs to the Aigentic Platform to track, evaluate and improve your agent
    implementation("community.flock.aigentic:platform:{{AIGENTIC_VERSION}}")

    // Choose one of the following Ktor client engines depending on your platform
    implementation("io.ktor:ktor-client-cio:{{KTOR_VERSION}}")         // Ktor's CIO engine
    //implementation("io.ktor:ktor-client-okhttp:{{KTOR_VERSION}}")    // JVM (Android compatible)
    // implementation("io.ktor:ktor-client-apache:{{KTOR_VERSION}}")   // Apache HttpClient
    // implementation("io.ktor:ktor-client-java:{{KTOR_VERSION}}")     // Java 11+ HttpClient
    // implementation("io.ktor:ktor-client-jetty:{{KTOR_VERSION}}")    // Jetty HttpClient
    // implementation("io.ktor:ktor-client-js:{{KTOR_VERSION}}")       // Javascript/Node
}
```

## Add a tool

Tools let an agent call your code. Here the agent gets a `getWeather` tool and decides on its own when to call it. It uses the imports from step 2, plus `community.flock.aigentic.core.annotations.Description`:

```kotlin
// Describe the agents response type
@AigenticParameter
data class WeatherResponse(
    @Description("Current temperature in degrees Celsius")
    val temperature: Double,
    @Description("Current weather conditions description")
    val conditions: String,
    @Description("Name of the location for the weather data")
    val location: String
)

// Describe the agents task input type
@AigenticParameter
data class WeatherQuestion(
  val city: String,
  val country: String
)

suspend fun main() {

    val agent = agent<WeatherQuestion, WeatherResponse> {

        // Configure the Gemini model for the agent
        geminiModel {
            apiKey("YOUR_API_KEY")
            modelIdentifier(GeminiModelIdentifier.Gemini3_5Flash)
        }

        // Configure the task for the agent
        task("Provide weather information") {
            addInstruction("Respond to user queries about weather")
        }

        // Add a weather tool
        addTool("getWeather", "Get the current weather for a location") { req: WeatherQuestion ->
            // Replace with a call to a real weather API
            WeatherResponse(temperature = 14.0, conditions = "Light rain", location = req.city)
        }
    }

    val run = agent.start(WeatherQuestion("Amsterdam", "Netherlands"))

    // Print the result
    when (val outcome = run.outcome) {
        is Outcome.Finished -> println("Weather in ${outcome.response?.location}: ${outcome.response?.temperature}°C, ${outcome.response?.conditions}")
        is Outcome.Stuck -> println("Agent is stuck: ${outcome.reason}")
        is Outcome.Fatal -> println("Error: ${outcome.message}")
    }
}
```

The run prints each step, so you can follow what the agent does:

```text title="Output (shortened)"
🚀 Agent started!
🏗 Executing tool: getWeather arguments: {"city":"Amsterdam","country":"Netherlands"}
🦾 Tool result getWeather: …
🏁 Agent finished! …
Weather in Amsterdam: 14.0°C, Light rain
```

:::caution Don't forget the Kotlinx serialization plugin
To use the @AigenticParameter annotation, you must include the Kotlinx serialization plugin in your build configuration. This plugin generates the metadata Aigentic needs to process your custom types when communicating with LLMs.
:::
